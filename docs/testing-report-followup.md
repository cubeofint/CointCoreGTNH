# Разбор результатов тестирования 14.11.2026

## Новые правила, подтверждённые владельцем

- Межсерверное исполнение `/fly`, `/god`, `/heal` отключено. Локальные команды и гостевые переключатели остаются.
- Вступление в SU-команду больше не запускает перенос отдельного игрока. Начатые ранее операции не удаляются: для восстановления остаётся прежний формат журнала.
- Лидер может запустить перенос всей своей команды через `/migrate ui`, без OP и без согласия остальных. Для лидера разрешено только направление `migrationQuestSourceNode` → `migrationQuestTargetNode` и только собственная команда. Другие административные подкоманды ему не открываются.
- Перед отключением участников есть предупреждение и 15 секунд. До отключения лидер может отменить запрос через `/migrate-confirm <ID> no`.
- Квест с настроенным UUID запускает перенос только от лидера. Старые незапущенные запросы согласования не возобновляются по новым правилам.

## Изменения интерфейса и гостевого режима

- В основном окне переноса убран выбор ZIP. Ник заполнен текущим игроком; администратор может указать другой. Команды ручного export/import остались административными.
- Метка сервера отображается только для удалённых игроков.
- Нажатие на стол с уже начатой игрой открывает наблюдение, если игрок не является участником. Наблюдатель может выйти и войти снова.
- На хабе разрешено взаимодействие именно с карточным столом, без разрешения гостям других блоков и предметов. Разрешение чужих стульев этим не добавляется.
- Исправлена вторая проверка доступа к fly/god: обычный командный обработчик учитывает выданное разрешение, оператор получает доступ. Явный запрет для обычного не-оператора сохраняется.

## Пока не подтверждено исправление

- Отказ whitelist при переходе командой, отличие от перехода через меню.
- Синхронизация OP, донатных рангов, покупок в гостях; устаревшие префиксы и лимит домов после изменения ранга.
- Причина незавершённых переносов из отчёта. Нужны журналы исходного и целевого узлов; старые операции нельзя повторно импортировать вслепую.
- Межсерверный `/home`: сейчас маршрутизация на домашнюю ноду есть у `/server home`, а не у штатного SU `/home`. Прежний чеклист ошибочно утверждал обратное.
- Выбор последних прогруженных чанков при истечении бонуса.
- Визуальное искажение шрифта в торговле и УНО, взаимодействие с конкретным блоком стула в чужом привате, временный отказ межсерверной торговли.
- Жалоба на выбор проигравшего УНО: требуется сопоставить конкретный раунд и руки участников. Проверка 27 против 80 очков добавлена отдельно; правило остаётся прежним — выбывает максимальная сумма оставшихся карт.

## Данные для продолжения

Запустить `tools/collect-cluster-test-report.sh` на основном Linux-хосте. Скрипт только читает данные трёх узлов, сохраняет отфильтрованные логи, версии JAR, whitelist/OP и найденные файлы рангов в `/root/coint-test-report-*.tar.gz`. Полный `cointcore.cfg`, JDBC URL и пароль БД в отчёт не включаются. Точные ник и время повторения ошибки помогут связать логи разных узлов.

Эта сборка — исправления подтверждённых путей и новых правил, а не закрытие всего отчёта. Массовые переносы до проверки одиночной тестовой команды не запускать.
